# Corridor Crowd Density Simulator Using NumPy

A simulation project built using **Python** and **NumPy** that models crowd movement inside a corridor represented as a 2D grid.

The simulator demonstrates how people move through a corridor while avoiding obstacles, identifies congested regions, and generates a local density heat map.

---

## Features

- Create a 2D corridor using NumPy arrays
- Randomly place obstacles
- Randomly place people
- Simulate crowd movement over multiple steps
- Detect congestion in crowded areas
- Generate a local density heat map
- Display the corridor using custom symbols

---

## Technologies Used

- Python 3
- NumPy

- Array iteration

---

## Grid Representation

| Symbol | Meaning |
|--------|---------|
| `.` | Empty Cell |
| `P` | Person |
| `X` | Obstacle |

---

## Simulation Workflow

1. Create an empty corridor.
2. Place obstacles randomly.
3. Place people randomly.
4. Simulate movement over multiple steps.
5. Detect crowded regions.
6. Generate a density heat map.
